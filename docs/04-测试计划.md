# ShopPilot 测试计划与冒烟测试

版本 v1.0，2026-10-13

## 测试范围

对项目各模块做端到端冒烟测试，确认每个入口能正常运行。

## 测试项

### T1 环境检查
- Python 版本（需 3.11）
- 虚拟环境是否激活
- 依赖是否完整安装
- .env 是否存在且 key 有效
- data/shop.db 是否存在

### T2 数据层
- seed.py 能否正常生成数据
- verify.py 能否验证 3 个预埋异常

### T3 MCP Server
- ecomdb_server 7 个工具能否调通
- review_server cluster_reviews 能否调通

### T4 Agent
- run_agent.py 对话能否正常回答
- health_check.py 一键体检能否召回异常
- generate_report.py 能否生成 Word 日报并入库

### T5 界面
- Streamlit 能否启动
- 三个 Tab 能否正常切换
- 问答流式输出是否正常
- 体检按钮能否正常工作
- 图表 Tab 能否渲染

### T6 API
- FastAPI 能否启动
- /api/healthz 是否返回 200
- /api/ask 能否回答

### T7 一键启动
- start.bat 双击能否完成环境检查并启动 Streamlit

## 发现并修复的问题

| 问题 | 原因 | 修复 |
|------|------|------|
| start.bat 双击报错 | .bat 文件是 UTF-8 编码，cmd.exe 默认 GBK 读取，中文乱码被当成命令 | 重写为纯英文版，彻底避开编码问题 |
| start.bat 双击后浏览器没弹 | Streamlit 启动需要几秒，cmd 窗口可能被忽略 | 脚本正常，手动打开 http://localhost:8501 即可 |
