# ShopPilot 7天冲刺开发计划（投递版MVP）

| 项目 | 内容 |
|------|------|
| 文档版本 | v2.0（7天冲刺版） |
| 创建日期 | 2026-10-12 |
| 计划周期 | 7天（2026-10-12 ~ 20-18） |
| 目标 | 做出可演示、有亮点、闭环完整的MVP，立即写进简历投递 |

> 每天预计投入6-8小时。原则：**先跑通主链路，再补亮点，最后包装**。宁可功能少但每个都能演示，不要做一堆半成品。

---

## 7天交付范围（冻结，不再加需求）

| 模块 | 7天版做到什么程度 |
|------|------------------|
| Mock数据库 | 45天数据、8个商品、5渠道，预埋3个明显异常 |
| MCP Server | **2个**：①数据查询（含5个工具）②评论分析（含3个工具） |
| 对话取数 | 自然语言查指标/趋势/排行，CLI+网页可用 |
| 异常归因 | 一键体检，自动检测异常并按"流量→转化→评论"路径归因 |
| 评论分析 | LLM批量情感分类 + LLM主题聚类（不用本地embedding，省下载和调试） |
| 日报 | Streamlit页面展示+导出Word（python-docx，模板固定） |
| 界面 | Streamlit 3个Tab：对话取数 / 一键体检 / 运营日报 |
| 可观测 | Langfuse（Day7有时间就接，没时间用日志兜底，不阻塞投递） |
| 评估 | 20题取数测试 + 3异常召回，数字写进README |

**明确不做：** 多轮复杂记忆、定时任务、query_sql兜底（Day3时间够再加）、HDBSCAN、多用户、真实平台API。

## 4（10/15）：异常检测 + 归因分析（核心亮点）

**今天结束要看到：输入"帮我体检"，Agent自动找出异常商品并讲清原因。**

- [ ] anomaly.py：环比阈值（跌30%）+ 偏离7日均值2倍标准差 检测
- [ ] detect节点：扫描8个商品，输出异常清单
- [ ] attribution_prompt：内置"流量→转化→商品→评论→退款"决策树
- [ ] attribution节点：针对异常商品依次取数（UV?渠道?转化?评论?库存?），每步返回发现
- [ ] conclude节点：汇总排查路径，输出"现象+根因+建议"
- [ ] 排查步数硬上限4步，防止跑飞
- [ ] 在3个预埋异常上验证：能检出≥2个并给出合理归因

## 风险控制（7天版）

| 如果Day... | 落后了怎么办 |
|-----------|-------------|
| Day1数据没做完 | 商品减到5个、天数减到30天，异常保留3个 |
| Day3取数正确率低 | 指标问题全走确定性工具，砍掉自由query_sql |
| Day4归因发散 | 不做LLM动态假设，改成固定4步排查流程（照样能演示） |
| Day5聚类不准 | 用预设6个主题让LLM硬分类，不做开放聚类 |
| Day6界面来不及 | 日报Tab简化为"表格+下载按钮"，图表只留1张趋势图 |
| Day7没时间 | 评估和README优先，Langfuse和GIF可投递后补 |

**底线：Day6结束必须有一个能从头到尾演示的完整闭环，Day7只做包装，不再加功能。**
