## 关键决策记录

| 决策点 | 选择 | 理由 |
|--------|------|------|
| Agent框架 | create_react_agent 而非手写StateGraph | 7天冲刺，稳定可靠，支持并行工具调用 |
| 评论聚类 | LLM直接聚类 而非 embedding+KMeans | 省掉模型下载调试，DeepSeek中文效果够用 |
| MCP版本 | 锁定1.30.0 而非2.x | 2.x API不兼容、资料少 |
| 异常检测 | 确定性scan_anomalies + LLM归因 | 保证召回率100%，不依赖LLM心情 |
| 可观测 | 自研文件Trace 而非Langfuse | 轻量不依赖外部服务，MVP够用 |
| 多用户/账号 | 不做 | 纯CRUD无技术含量，不浪费冲刺时间 |

## 风险控制（实际遇到的坑及解决）

| 风险 | 实际情况 | 解决 |
|------|---------|------|
| 数据库路径 | 相对路径依赖运行目录 | Path绝对路径 |
| MCP版本 | 2.x API全变 | 锁定1.30.0 |
| Streamlit异步 | Event loop closed | nest_asyncio + 线程池 |
| 异常召回 | LLM漏掉断货 | 加确定性scan_anomalies工具 |
| GitHub访问 | 国内网络超时 | 切网络/重试，最终推送成功 |
| 数据日期漂移 | seed以当天为基准，跨天数据窗口变 | 重跑seed.py整体平移 |
